PLAYLIST COVERS — drop your pictures in this folder.

Name each picture after the playlist's id (src/data/musicLinks.ts):

    hot-stuff.jpg
    mac-demarco.jpg
    radiohead.jpg

.jpg .jpeg .png .webp .avif all work. The tile is 4:5 (portrait), so a picture around
800 x 1000 px looks best; a square picture also works (the sides are trimmed a little).

Want a mosaic of several pictures (like "Hot Stuff" had)? Instead of one file, make a FOLDER
with the id as its name and put 2, 4 or 6 pictures inside:

    hot-stuff/1.jpg
    hot-stuff/2.jpg
    hot-stuff/3.jpg
    hot-stuff/4.jpg

No picture for a playlist? It shows a generated record cover — nothing breaks.
